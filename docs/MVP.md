## 1. 사용자 확정 범위

2026-10-25 사용자가 1A / 2A / 3A를 선택했다.

1. 법규·판례는 준비된 JSON을 사고 도표번호 chart_no로 정확조회한다. PDF 청킹·임베딩·Chroma·검색형 RAG는 이번 제출에서 제외한다.
2. 현재 YOLO 첫 차량 검출 프레임 저장 기능을 유지한다. ‘사고 장면 탐지’가 아닌 ‘차량 감지 장면’으로 설명한다.
3. 기존 서버와 화면을 최소 수정한다. 문답·수정·영상 기능을 다시 만들거나 기술 스택을 교체하지 않는다.

사용자는 추가로 **저장된 협회 비율·기본 해설 사용**과 **자료의 차량 A/B 그대로 표시**를 선택했다. 실시간 검색·AI 생성·내 차량 지정 질문은 이번 제출 범위에서 제외한다. 새 모델·API 키·패키지 설치는 필요하지 않다.

## 2. 서비스와 사용자 흐름

차대차 사고의 상황을 선택하고 짧은 영상 한 개를 첨부하면, 문답에 맞는 비율·해설과 법규·판례, 영상의 차량 감지 사진을 확인하는 반응형 웹앱이다. 영상은 과실비율 판단에 사용하지 않는다.

1. 저장된 질문·선택지에 답하고 서버에 저장한 후 다음 질문으로 진행한다. 이전 문답과 분기를 유지한다.
2. 마지막 답변 후 사고 상황을 정리하고 영상 첨부를 안내한다.
3. 영상 한 개를 업로드하고 전송·대기·처리 상태를 확인한다.
4. 검사한 프레임 중 차량이 처음 검출된 장면을 저장한다. 미검출·처리 실패는 별도로 안내한다.
5. 완료 문답의 도표번호로 저장된 협회 비율·기본 해설과 법규·판례를 조회한다.
6. 결과에서 사진 또는 영상 처리 안내, 사고 상황, 비율·해설, 법규, 판례와 각 출처를 확인한다.

## 4. 문답·수정 규칙

- 현재 문답 서비스·SQLite·질문 데이터와 v1/v2 계약을 유지한다. 웹앱은 명시 v2 데이터를 사용한다.
- 수정 취소·같은 답변 확정은 기존 이력과 결과를 유지한다.
- 다른 답변으로 확정하면 이후 문답을 지우고 새 분기로 진행하며 revision을 증가시킨다.
- 영상·결과는 session_id와 revision에 연결한다. 수정 후 이전 결과를 재사용하지 않는다.
- 법규·판례 조회는 서버 내부 get_context의 검증된 chart_no를 사용한다. 내부 파일경로·증빙을 포함한 context 전체는 공개하지 않는다.
- 차량은 협회 자료의 A/B로 표시한다. 내 차·상대 차로 대응시키거나 이를 위한 추가 질문을 만들지 않는다.

## 5. 영상 처리

- 기존 OpenCV·YOLO 차량 검출을 유지한다. 사고 전용 데이터셋·가중치 학습은 이번 작업에서 제외한다.
- 현재 제한은 200MB·2분·4K 이하, MP4/MOV/AVI/MKV/WebM이다. 확장자만으로 모든 코덱 지원을 보장하지 않는다.
- 약 0.5초 간격으로 검사하고 점수 0.5 이상의 승용차·오토바이·버스·트럭이 처음 검출된 프레임을 저장한 뒤 종료한다.
- 원본 사진·검출 표시 사진·확대 기능을 보존한다. 모델 점수는 사고 확률이나 과실비율이 아니다.
- 미검출은 검사한 프레임에서 기준 이상의 차량을 찾지 못했다는 뜻이다. 차량이 없거나 사고가 없다고 단정하지 않는다.
- 영상 미검출·처리 실패와 문답 기반 결과를 분리한다. 영상 업로드 없이 결과를 요청할 수는 없다.

## 6. 법규·판례 데이터

- 팀 PDF에서 만든 data/legal_references_by_chart.json을 사용한다. 사용자가 PDF를 올리는 화면은 만들지 않는다.
- 108개 도표의 법규, 77개 도표의 판례·조정사례가 있다. 원문 묶음 하나에 여러 조항·사건이 들어 있을 수 있다.
- 각 자료의 id, content, source_url, pdf_name, pdf_pages를 유지한다. PDF 페이지는 1부터 시작한다.
- 현재 v2의 108개 완료 경로가 도표번호로 연결돼 있다. 자료가 없는 도표는 자료 없음으로 안내한다.
- 31개 도표는 제공된 판례 PDF에 해당 자료가 없다. 빈 목록으로 표시하며 판례 자체가 없다고 단정하거나 유사 판례를 임의로 대체하지 않는다.
- 긴 원문은 접어서 전체 내용을 펼쳐 볼 수 있게 한다.
- JSON 정확조회를 벡터 검색 RAG나 AI 검색으로 표시하지 않는다.

## 7. 결과·실패 처리

결과 순서는 차량 감지 사진/처리 안내 → 사고 유형 → 비율·해설 → 법규 → 판례다.

- 비율은 실제 근거 자료의 값만 사용한다. 유효한 A/B 값의 합이 100이 아니거나 자료가 없으면 확인 불가로 안내한다.
- 비율·해설은 data/accident_cases.json의 협회 저장 자료임을 표시하고 해당 도표 원문 URL을 제공한다. 실시간 검색·AI 생성 결과라고 표시하지 않는다.
- 한 기능의 실패가 다른 유효한 결과를 지우지 않게 한다.
- 답변 수정·새 영상·새 대화 이후 늦게 도착한 응답은 폐기한다.

| 영역 | 현재 구현·수정 대상 |

추가 결과 경로는 GET /video-jobs/{job_id}/result다. 최신 문답이 완료됐고 해당 revision으로 업로드한 영상 처리가 종료됐는지 확인한다. 실제 반영 상태는 현재 작업 계획을 따른다.

## 9. 완료 기준·제외 범위

- 기존 문답·저장·수정·영상 기능을 유지하면서 문답에 맞는 결과를 제공한다.
- 법규·판례의 도표번호·원문·출처·PDF 페이지가 대응한다.
- 자료 없음·차량 미검출·처리 실패를 구분한다.
- 저장된 협회 기본 비율·해설과 자료의 차량 A/B 표시를 연결한다.
- 변경 경로만 가볍게 확인하고 완료·미완료를 문서에 남긴다.

제외: 로그인·회원가입, 과거 분석 이력, 가감요소 계산, 영상 기반 과실비율 판단, 사고 전용 모델 학습, 수동 사고 시점 선택, 검색형 RAG 구축, Tavily 실시간 검색, Ollama·Gemma AI 생성, 내 차량 A/B 지정 질문, 별도 모바일 앱, Next.js/FastAPI 전환, 광범위한 리팩터링.

새 패키지·모델·의존성 다운로드·설치 전에 항목·출처·위치·예상 변경과 사용자 승인이 필요하다. 새 기능 범위나 도구 선택도 임의 확정하지 않는다.
